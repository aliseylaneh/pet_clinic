# Pet Clinic

A simple Java Spring Boot application for managing a veterinary clinic.  
This project is a practice application focused on learning and applying Spring Boot fundamentals, object-oriented design, and backend development concepts.

## Features

- Manage pet owners
- Manage pets
- Manage veterinarians
- Manage clinic information
- Basic CRUD operations
- RESTful API development

## Tech Stack

- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- Maven
- MySQL

## Purpose

The goal of this project is to explore backend development using the Spring ecosystem, including:

- Spring Boot application structure
- Dependency injection
- REST API design
- Database persistence with JPA/Hibernate
- Entity relationships
- Clean backend development practices

## Status

This project is currently a basic implementation for learning and experimentation with Java Spring Boot and it's archived.
